# ICoN10 Conference Website — Version 3

This is a static HTML, CSS, and JavaScript website prepared for GitHub Pages.

## Main pages

- `index.html`: home page
- `program.html`: conference program
- `speakers.html`: invited speakers
- `registration.html`: registration information
- `abstract.html`: abstract submission
- `venue.html`: venue overview
  - `venue-transportation.html`: transportation
  - `venue-accommodation.html`: accommodation
  - `venue-local-information.html`: local information
- `organization.html`: committees and sponsors
- `code-of-conduct.html`: code of conduct

## Shared design files

- `css/style.css`: KAIST color tokens, shared components, page-specific rules, and responsive rules
- `js/main.js`: shared navigation, home slider, program notices, and abstract dialog

## Information box classes

- `info-box info-box--note`: short orange note without a heading
- `info-box info-box--feature`: blue information block with a heading and optional eyebrow
- `info-box__eyebrow`: small uppercase label inside a blue information block
- `info-box__title`: heading inside a blue information block
