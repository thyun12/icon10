# ICoN10 Conference Website

This is a static HTML, CSS, and JavaScript website prepared for GitHub Pages.

## Main pages

- `index.html`: home page
- `program.html`: conference program
- `speakers.html`: invited speakers
- `registration.html`: registration information
- `abstract.html`: abstract submission
- `venue.html`: venue overview
  - `transportation.html`: transportation
  - `accommodation.html`: accommodation
  - `local-information.html`: local information
- `organization.html`: committees and sponsors
- `code-of-conduct.html`: code of conduct

## Shared design files

- `css/style.css`: KAIST color tokens, shared components, page-specific rules, and responsive rules
- `js/main.js`: shared navigation, home slider, program notices, and abstract dialog
